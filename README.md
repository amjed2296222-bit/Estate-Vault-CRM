# Estate Vault CRM

An independent, secure, and offline-first Real Estate Operating System & CRM built with React 19, TypeScript, and Tailwind CSS.

## Overview
Estate Vault CRM is a local real-estate management system designed for property brokerages, agents, and syndicates. All customer records, listings, cashflow transactions, investor ledgers, and configurations are securely stored on the local client device without requiring external internet or cloud server access.

## Core Features
1. **Property Inventory & Catalog**:
   - Comprehensive property listings across Plots for Sale, Homes for Sale, Homes for Rent, and Personal Assets.
   - Deep architectural parameters: Plot #, Street, Block, Society, Marla/Kanal dimensions, Google Maps links.
   - Financial pricing with automatic South Asian numeric words conversion (PKR with Lakhs and Crores).
   - Interactive checklist for 100% Paid Development & Utility Charges (Land, Utilities, Possession, Gas, Electricity, Water).
   - Dynamic Remaining Dues tracker for pending installments and transfer fees.
   - AI-powered smart marketing description generator.
   - Photo gallery with cover image selector.

2. **Clients & Contacts Directory**:
   - Categorized by Client / Buyer, Property Owner / Seller, and Realtor / Dealer.
   - Tracks phone, WhatsApp, location, budget, follow-up reminders, and Khata balance.

3. **Leads Management Pipeline**:
   - Visual Kanban board and list view across deal stages: New, Contacted, Visit Scheduled, Negotiation, Closed Won, Lost / Dropped.
   - Track inquiry sources (Facebook, WhatsApp, Direct Call, Walk-in).
   - 1-click conversion from Lead to permanent Client record upon deal finalization.

4. **Accounts & Khata Ledger**:
   - Double-entry income and expense tracker with net financial cashflow metrics.
   - Filter by payment method (Cash, Bank Transfer, Cheque, Online Deposit), category, date, and linked society.
   - 1-click CSV spreadsheet export and printable formal statement.

5. **Investors Ledger**:
   - Dedicated equity syndicate manager for property flipping and joint-ventures.
   - Automatic calculations of gross profit, net margins, custom investor profit-share percentage, and return on investment (ROI).
   - Complete transaction journal with running balances (debit/credit) and printable investor statements.

6. **Smart Share Marketing Hub**:
   - Canvas-based image marketing card generator with instant PNG download.
   - Formatted WhatsApp brochure generator with emojis and bold styling.
   - Printable property marketing flyer.

7. **Universal Dropdown Taxonomy**:
   - Centralized database manager for Societies, Blocks, Sizes, Property Types, Unit Types, Lead Sources, and Payment Methods.

8. **User & Permissions Administration**:
   - Local authentication and access control.
   - Granular permissions matrix (view, add, edit, delete properties, accounts, investors, and settings).
   - Audit trail of recent system activity logs.

9. **Recycle Bin (Safety Archive)**:
   - Recovers accidentally deleted properties, transactions, clients, and leads with 1-click restoration.

10. **Settings, Security & Offline Backups**:
    - Real estate agency profile customization.
    - 4-digit PIN / Biometric screen lock.
    - Complete JSON backup export and restore with replace or merge modes.

## Getting started

On first launch, create a Super Admin account with a unique username and a password of at least 12 characters. Email is optional. No default login credentials are provided.

Application records are stored in the browser on the current device. Export backups regularly and keep them in a secure location.
